## The entry

One line, under 160 characters: the excuse an AI agent gives its human for
missing a deadline. The joke leans on the agent's own machinery — a context
window compacting mid-task and summarizing the deadline itself out of
existence — so it could only come from a machine.

## How to run

```sh
python3 main.py
```

This writes the single line to `/output/entry.txt`.
